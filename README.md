# Assessoria & Consulta — Next.js

Landing page institucional baseada no primeiro conceito aprovado, com visual direto e animações premium.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Onde editar

- Conteúdo, cards, depoimentos, FAQ e número do WhatsApp: `components/LandingPage.tsx`
- Cores, espaçamentos, responsividade e animações: `app/globals.css`
- Título e descrição SEO: `app/layout.tsx`
- Imagem principal: `public/hero-reference.png`

## Antes de publicar

Troque o número `5500000000000`, os contatos, os links sociais, os dados do footer e os textos institucionais pelos dados reais da empresa.
